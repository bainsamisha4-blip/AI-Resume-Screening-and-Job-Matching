# AI Resume Screening and Job Matching System

## About the Project
This project uses Natural Language Processing (NLP) techniques to explore resume and job description matching.

## Objectives
- Analyze resume text and job descriptions.
- Calculate text similarity using TF-IDF and Cosine Similarity.
- Explore semantic similarity using Sentence-BERT.
- Identify relevant skills and support candidate ranking.

## Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Sentence-Transformers
- Jupyter Notebook

## Project Files
- `AI_Resume_Project.ipynb` — Jupyter Notebook containing the project code and analysis.
- Dataset files — to be added.

## How to Run
1. Download the notebook and required dataset.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook.
4. Run the cells in order.

## Dataset

This project uses the LinkedIn Job Postings (2023–2024) dataset from Kaggle.

**Dataset Source:** https://www.kaggle.com/datasets/arshkon/linkedin-job-postings

Download the dataset from Kaggle and place the required CSV file (`posting.csv`) in the project folder before running the Jupyter Notebook.
